El ERP tiene cuatro tablas: empresa, cuenta, asiento y partida. No existe ninguna tabla para el Libro Mayor ni para el Balance: por eso es imposible cargarlos a mano, siempre se calculan a partir de los asientos confirmados del Libro Diario.
